live broker connectors (IBKR, Kraken) and trade execution. I need a hard, unmissable
boundary so that (a) every simulated result is clearly labeled everywhere it appears,
and (b) there is NO code path from a simulated backtest result to a real broker order.

refactor unrelated code.

  - backtestResultSchema (general backtests)
