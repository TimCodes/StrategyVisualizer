# Praxis — QuantConnect LEAN Integration Prompt

## Project Context

I have an existing full-stack algorithmic trading dashboard called **Praxis** (repo: `https://github.com/TimCodes/StrategyVisualizer`). It is a monorepo (NPM Workspaces) with three packages:

- `@app/client` — React 18 + TypeScript + Vite + shadcn/ui + Tailwind (dark theme) + Recharts + TanStack Query + Wouter
- `@app/server` — Express + TypeScript + Socket.IO + Drizzle ORM + PostgreSQL (Neon)
- `@app/shared` — Zod schemas + Drizzle table definitions

The app already supports: strategy CRUD, backtesting (Monte Carlo simulation), portfolio management, live crypto market data (CoinGecko/Kraken), multi-LLM chat (OpenAI/Anthropic/Gemini), LLM Arena, risk management, and settings. Deployment target is Replit Autoscale.

**I need to add three major features:**

1. **QuantConnect LEAN CLI integration** — real backtesting engine replacing the current Monte Carlo simulation
2. **Monaco code editor** — VS Code-like Python editor for writing/editing LEAN strategies in the browser
3. **AI Strategy Agent** — an LLM-powered agent that generates new LEAN-compatible Python strategies using the QuantConnect LEAN library API

### Environment Setup

The LEAN CLI requires Docker. Add to the Replit environment:

1. Install `lean-cli` via pip: `pip install lean`
2. Run `lean init` in the project root to create the `lean.json` config
3. Ensure Docker is available (Replit may need a Docker-in-Docker or alternative approach — if Docker is unavailable on Replit, fall back to running LEAN directly via `dotnet` with the open-source LEAN engine cloned as a submodule)
4. Set environment variable `LEAN_CLI_INSTALLED=true` in `.env`

### Fallback: Direct LEAN Engine (No Docker)

If Docker is not available on Replit, clone the LEAN engine and run directly:

```bash
git clone https://github.com/QuantConnect/Lean.git lean-engine
cd lean-engine
dotnet build QuantConnect.Lean.Launcher
```

Then modify the service to spawn:
```bash
dotnet run --project lean-engine/QuantConnect.Lean.Launcher -- --config config.json
```

Where `config.json` points to the user's strategy file and data directory.

### Component: `StrategyEditor.tsx`

Create at `packages/client/src/components/strategy-editor/StrategyEditor.tsx`:

```tsx
// Full-featured strategy editor with:
// 1. Monaco editor configured for Python with vs-dark theme
// 2. LEAN API autocomplete (custom completions for QCAlgorithm, self.AddEquity, etc.)
// 3. Template selector dropdown — pre-built LEAN strategy templates
// 4. "Run Backtest" button that POSTs code to /api/lean/projects/:name/backtest
// 5. Real-time backtest log output panel below the editor (fed by Socket.IO)
// 6. Split-pane layout: editor on left, results/charts on right
// 7. File tree sidebar showing LEAN project files
// 8. Save/Load project functionality

import Editor, { Monaco } from '@monaco-editor/react';
import { useSocket } from '../../hooks/useSocket';

interface StrategyEditorProps {
    projectName: string;
    initialCode?: string;
    onBacktestComplete?: (results: BacktestResult) => void;
}

export function StrategyEditor({ projectName, initialCode, onBacktestComplete }: StrategyEditorProps) {
    const [code, setCode] = useState(initialCode || DEFAULT_LEAN_TEMPLATE);
    const [logs, setLogs] = useState<string[]>([]);
    const [isRunning, setIsRunning] = useState(false);
    const socket = useSocket();

    // Listen for backtest streaming events
    useEffect(() => {
        if (!socket) return;
        socket.on('lean:backtest:log', (line: string) => {
            setLogs(prev => [...prev, line]);
        });
        socket.on('lean:backtest:complete', (results) => {
            setIsRunning(false);
            onBacktestComplete?.(results);
        });
        socket.on('lean:backtest:error', (error) => {
            setIsRunning(false);
            setLogs(prev => [...prev, `ERROR: ${error}`]);
        });
        return () => {
            socket.off('lean:backtest:log');
            socket.off('lean:backtest:complete');
            socket.off('lean:backtest:error');
        };
    }, [socket]);

    const handleEditorMount = (editor: any, monaco: Monaco) => {
        // Register LEAN Python autocomplete provider
        registerLeanCompletions(monaco);
    };

    const handleRun = async () => {
        setIsRunning(true);
        setLogs([]);
        const response = await fetch(`/api/lean/projects/${projectName}/backtest`, {
            method: 'POST',
            body: JSON.stringify({ code }),
            headers: { 'Content-Type': 'application/json' }
        });
        const data = await response.json();
        // Results also arrive via Socket.IO for streaming
    };

    return (
        <div className="flex flex-col h-full">
            {/* Toolbar: Run button, template selector, save, project name */}
            <div className="flex items-center gap-2 p-2 border-b border-border">
                <Button onClick={handleRun} disabled={isRunning}>
                    {isRunning ? <Loader2 className="animate-spin" /> : <Play />}
                    {isRunning ? 'Running...' : 'Run Backtest'}
                </Button>
                <TemplateSelector onSelect={setCode} />
                <span className="text-sm text-muted-foreground ml-auto">{projectName}</span>
            </div>

            {/* Split: Editor + Results */}
            <div className="flex flex-1 overflow-hidden">
                <div className="flex-1 min-w-0">
                    <Editor
                        height="100%"
                        defaultLanguage="python"
                        theme="vs-dark"
                        value={code}
                        onChange={(val) => setCode(val || '')}
                        onMount={handleEditorMount}
                        options={{
                            fontSize: 14,
                            minimap: { enabled: false },
                            scrollBeyondLastLine: false,
                            automaticLayout: true,
                            tabSize: 4,
                        }}
                    />
                </div>

                {/* Log output panel */}
                <div className="w-80 border-l border-border bg-background overflow-y-auto p-2 font-mono text-xs">
                    {logs.map((line, i) => (
                        <div key={i} className={line.includes('ERROR') ? 'text-red-400' : 'text-muted-foreground'}>
                            {line}
                        </div>
                    ))}
                </div>
            </div>
        </div>
    );
}
```

```python
from AlgorithmImports import *

class MovingAverageCrossover(QCAlgorithm):
    def initialize(self):
        self.set_start_date(2022, 1, 1)
        self.set_end_date(2023, 12, 31)
        self.set_cash(100000)

        self.spy = self.add_equity("SPY", Resolution.DAILY).symbol
        self.fast = self.sma(self.spy, 20, Resolution.DAILY)
        self.slow = self.sma(self.spy, 50, Resolution.DAILY)
        self.set_warm_up(50)

    def on_data(self, data):
        if self.is_warming_up:
            return
        if self.fast.current.value > self.slow.current.value:
            self.set_holdings(self.spy, 1.0)
        else:
            self.liquidate(self.spy)
```

## Feature 3: AI Strategy Generation Agent

### Overview

Add an AI agent that generates complete, runnable QuantConnect LEAN Python strategies from natural language descriptions. The agent uses the existing multi-LLM infrastructure (OpenAI/Anthropic/Gemini) with a specialized system prompt containing LEAN API documentation and examples.

### Agent Service (`packages/server/services/lean-agent.ts`)

```typescript
// The LEAN Strategy Agent:
// 1. Takes a natural language strategy description from the user
// 2. Uses the LLM (user's choice of provider) with a LEAN-specialized system prompt
// 3. Generates a complete, runnable QCAlgorithm Python class
// 4. Validates the generated code has required structure (class, Initialize, OnData)
// 5. Optionally auto-runs a backtest on the generated code
// 6. Can iteratively refine based on backtest results or user feedback

export interface StrategyGenerationRequest {
    description: string;           // "Create a momentum strategy that rotates between top 5 S&P 500 sectors monthly"
    provider: 'openai' | 'anthropic' | 'gemini';
    model?: string;                // specific model variant
    constraints?: {
        startDate?: string;
        endDate?: string;
        initialCapital?: number;
        assets?: string[];         // e.g., ["SPY", "QQQ", "IWM"]
        maxDrawdown?: number;      // risk constraint
        rebalanceFrequency?: string;
    };
    autoBacktest?: boolean;        // automatically run backtest after generation
    refinementContext?: {          // for iterative refinement
        previousCode: string;
        backtestResults?: any;
        userFeedback: string;
    };
}

export interface StrategyGenerationResult {
    code: string;                  // Complete Python strategy code
    explanation: string;           // Natural language explanation of the strategy
    parameters: Record<string, any>; // Extracted configurable parameters
    backtestResults?: any;         // If autoBacktest was true
}
```
